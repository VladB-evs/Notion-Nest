# NotionNest

Free, minimal, black-and-white widgets you can embed straight into Notion.
No accounts, no sign-in — just copy an embed link and drop it into a Notion
page with `/embed`.

## Widgets

- **Year Progress** — a grid of dots, one per day of the year. Past days
  are filled in, today glows red, the rest stay gray. Updates itself
  automatically at midnight.

More widgets coming over time.
